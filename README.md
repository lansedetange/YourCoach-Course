# YourCoach Course

《从零开发并上线同城健身私教预约微信小程序》是一套面向初学者的中文项目制课程。学员会按 00–37 阶段完成用户端小程序、私教端小程序、PC 管理后台及微信云开发后端的设计、开发、测试和上线准备。

## 从这里开始

1. 阅读[课程总纲](docs/课程总纲.md)，确认 38 节课的学习顺序。
2. 阅读[课程写作规范](docs/课程写作规范.md)，按统一结构学习和维护课程。
3. 从[第 00 课](course/00-导学与学习方法/00-课程使用说明与最终成果.md)开始，并为项目文档使用 `docs/` 中的模板。
4. 在仓库根目录运行 `node scripts/audit-course.mjs`，检查课程文件、固定栏目和总纲链接。

## 课程产出

- 用户端与私教端微信小程序
- PC 管理后台
- 微信云开发后端、云数据库与云存储设计
- 预约、订单、支付、退款、核销、评价和运营流程文档
- 测试、部署、审核、发布与持续运营资料

## 范围与安全

课程的第一版只支持同城、线下到店、一对一私教预约；不包含上门、团课、直播、社区或即时聊天。金额使用整数分，订单、支付、退款和核销等敏感操作由后端执行，前端不能直接修改订单状态。

不要在仓库提交 AppID、支付密钥、证书、手机号、身份证件或任何个人资料。所有示例均应使用占位符和环境变量。微信平台的规则、入口和资质会变化：**执行时请以微信公众平台当前页面和官方文档为准。**

## 仓库结构

- `course/`：按学习顺序排列的 38 节课程。
- `docs/`：课程总纲、写作规范和项目文档模板。
- `scripts/audit-course.mjs`：无需第三方依赖的课程审计脚本。

本轮仅建设课程文档，不提供可投产的业务代码、支付代码或云函数实现。
