# 课程名称：04 开通微信云开发

### 本课目标

在微信开发者工具中理解并安全开通或连接云开发环境，明确云数据库、云存储、云函数和环境隔离的基础用途。

### 你将完成

你能为开发阶段创建或选择一个开发云环境，记录环境状态和占位符；能说明为什么订单、支付、退款和核销逻辑必须经云函数等后端执行。

### 前置条件

1. 已完成第 03 课，拥有可用于开发的小程序账号或获得管理员授权。
2. 已安装或准备安装微信开发者工具；若尚未安装，本课可先阅读，具体安装在第 05 课完成。
3. 明确本课只处理开发环境，不将真实生产数据用于练习。
4. 执行时请以微信公众平台当前页面和官方文档为准。

### 核心概念

- **云环境**：一组隔离的云资源，通常区分开发、测试和生产。
- **云数据库**：按集合保存结构化数据的服务；例如后续的用户、教练和订单。
- **云存储**：保存图片、证书文件等对象的服务，必须配置访问规则。
- **云函数**：后端运行单元，接收请求后校验身份和业务规则。
- **环境 ID**：标识云环境的名称或 ID；不是密码，但不应随意公开真实生产值。

### 本课范围

本课只完成环境创建或连接、状态记录和安全认识。不要创建真实订单集合，不写业务云函数，不部署生产环境，不上传教练证书，不接入支付，更不把密钥放进前端配置。

### 关键决策

默认先建立一个开发环境 `<DEV_CLOUD_ENV_ID>`，再在后续课程建立测试和生产隔离。前端只请求云函数；云函数才有资格按权限规则操作订单、支付、退款和核销。这样能防止用户在浏览器或小程序中伪造状态。

```text
开发者工具 → 选择小程序项目 → 云开发入口 → 创建/选择开发环境
                                         ├→ 云数据库（结构化数据）
                                         ├→ 云存储（受控文件）
                                         └→ 云函数（可信业务逻辑）
```

### 操作前检查

1. 确认登录的是获得授权的开发账号，而不是陌生共享账号。
2. 检查当前项目对应用户端或私教端 AppID，不要把两个端的配置混在一起。
3. 在学习记录先写 `<DEV_CLOUD_ENV_ID>`、`<TEST_CLOUD_ENV_ID>`、`<PROD_CLOUD_ENV_ID>`，不写真实值。
4. 准备好停止条件：出现收费、权限、地区或主体资格提示且不理解时，暂停并查当前官方说明。

### 步骤 1

1. 打开微信开发者工具，使用获得授权的账号登录。
2. 从当前页面创建或打开对应小程序项目；若尚未有工程，只查看云开发入口，不要用未知模板替代课程工程。
3. 在工具侧边栏或菜单中查找当前标为“云开发”的入口；页面位置可能更新，以当前工具说明为准。
4. 预期结果：能看到开通、创建环境或选择环境的真实入口。

### 步骤 2

1. 按页面当前引导创建或选择一个明确标记为“开发”的环境。
2. 不把环境命名为含姓名、手机号、客户名称或密码提示的字符串；使用团队可识别的非敏感命名规则。
3. 创建后仅在受控位置记录真实环境 ID；课程仓库写 `<DEV_CLOUD_ENV_ID>`。
4. 预期结果：开发者工具显示当前连接的开发环境或真实的待开通状态。

### 步骤 3

1. 在云开发控制台依次查看“数据库、存储、云函数”能力的说明或页面，不创建业务数据。
2. 写下用途：数据库保存结构化记录，存储保存受控文件，云函数执行可信逻辑。
3. 检查是否能看到环境切换位置；若可见，确认当前不是生产环境。
4. 预期结果：能复述三类资源的用途和环境隔离原因。

### 步骤 4

1. 在学习记录写下后续安全规则：订单状态只由后端变更；金额用整数分；支付回调由后端验证；文件访问按最小权限配置。
2. 记录当前环境状态，例如 `<DEV_ENV_STATUS: CREATED_OR_PENDING>`。
3. 若需要给同学或 Codex 描述问题，只提供错误摘要、工具版本和占位符，不提供环境截图中的敏感资料。
4. 预期结果：开通结果可追踪，且没有把生产权限或秘密扩散出去。

### 常见问题

- **找不到云开发入口**：确认开发者工具版本、当前登录账号权限和当前打开的项目；不要下载不明插件。
- **创建时提示权限或资格不足**：记录提示文字的非敏感部分，交由账号管理员核验；不要借用他人账号。
- **误把生产环境作为开发环境**：立即停止写入，确认环境名称和控制台标识；后续建立明确隔离的开发环境。
- **认为开通后可以前端直写订单**：资源存在不代表权限设计正确；订单规则仍要在云函数和数据库权限中实现。

### 安全与合规

云环境权限、数据库记录、存储文件、日志和函数配置都可能包含个人或业务数据。生产环境应最小授权、独立管理；真实密钥只使用受控环境变量或平台安全配置，绝不写入小程序前端、Markdown、终端输出或 Git。云开发产品能力和控制台入口可能变化。执行时请以微信公众平台当前页面和官方文档为准。

```text
角色：你是谨慎的微信云开发课程助教。
任务：仅审阅第 04 课的云开发开通与环境隔离说明，找出不安全、不可验证或对初学者不清楚之处。

```
