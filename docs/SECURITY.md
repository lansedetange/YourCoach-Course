# 安全设计

## 安全基线

所有客户端和外部回调均不可信。后端从可信上下文获取身份，校验权限、对象归属、输入、金额、当前状态、幂等和审计；数据库权限遵循最小化和默认拒绝。凭据仅通过受控密钥管理或环境变量注入，绝不进入仓库、日志、截图或前端包。

| 资产或流程 | 主要风险 | 控制措施 | 验证证据 |
| --- | --- | --- | --- |
| 用户、教练、管理员身份 | 冒用/越权 | 可信登录态、角色状态、对象归属校验 | 越权读写请求被拒绝 |
| 订单与排期 | 状态篡改/并发抢位 | 后端状态机、事务/条件写入、幂等键、审计日志 | 双请求仅一笔有效订单 |
| 支付与退款 | 伪造/重复记账/金额不符 | 服务端验签、金额/归属校验、查单、外部交易号唯一性 | 重复/金额不符无副作用 |
| 钱包与提现 | 超额/篡改 | 整数分、流水追加、钱包事务、审核与对账 | 余额与流水一致、越权被拒绝 |
| 证书、位置、个人资料 | 过度收集/公开 | 最小字段、公开/本人/审核分层、短时位置使用 | 无权读取被拒绝、日志脱敏 |
| 管理后台 | 权限扩大/不可追溯操作 | 后端 RBAC、二次确认、理由、不可变审计 | 非管理员/重复操作被拒绝 |
| 密钥与配置 | 泄露/错误环境 | 受控注入、环境隔离、代码扫描、轮换流程 | 仓库/构建物无秘密 |
| 日志与通知 | 敏感泄露/过度投递 | 脱敏字段、最小内容、事件去重、访问限制 | 日志/模板无敏感值 |

## 隐私与日志原则

- 每个数据字段须有明确用途、可见角色、保留/删除/导出边界；非必要字段不收集。
- 用户位置可选、短时使用；证书、支付、提现和审核资料不公开。
- 日志仅记录请求 ID、脱敏对象摘要、错误分类和结果；不记录令牌、签名、证书、完整身份标识、精确位置、银行卡或支付原文。
- 未通过的高风险项为上线阻断项，不能以“后续修复”替代。
