# 课程总纲

本课程按实际交付顺序组织为 38 个阶段。先解决主体、账号和合规，再完成产品设计、工程与数据基础，随后建设三端和交易履约，最后测试、审核、发布和运营。涉及微信平台规则时，**执行时请以微信公众平台当前页面和官方文档为准。**
